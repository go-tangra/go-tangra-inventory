# inventory join bundle

Generated by the gateway (Gateway operations › Modules › inventory › Add).

    docker compose up -d

The module applies its database migrations on start and enrolls for its
mesh identity with the single-use token.

`private/` holds credentials (the enrolment token, the bundle's TLS keys);
`.env` and `config.yaml` hold generated passwords and the module KEK. Keep
them on this host only, and keep a copy of `.env`: without `GEN_KEY_1` the
stored agent credentials cannot be opened.

**Agents.** The ingest edge listens on `INGEST_PUBLIC_PORT` with a
certificate for the name `inventory-ingest` from this bundle's local CA.
Point agents at it with that CA pinned:

    ingest_endpoint: <this host>:<INGEST_PUBLIC_PORT>
    ca_file: /etc/inventory-agent/ingest-ca.pem    # a copy of private/tls/ca.pem
    server_name: inventory-ingest

Or replace `private/tls/inventory-ingest.crt` and `.key` with a certificate
for the name agents dial (chain, leaf first) and run `docker compose up -d`
again; agents then need neither `ca_file` nor `server_name`.
